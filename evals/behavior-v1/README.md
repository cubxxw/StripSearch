# Behavior v1 · 研究判断

8 个原创合成案例、18 份短材料，覆盖：团队贡献、计划与交付、选择性评论、因果克制、投入自述、证据更新、回忆与当时记录、资料稀疏。每题包含问题、来源、应保留事实、禁止推断和逐条 rubric。

当前全部 `discovery / unreviewed / not_run`。这是待评审的规格；尚无 Agent 回答，不能报通过率。材料只从 [fixtures.json](fixtures.json) 读取，禁止抓取 example.org。原创内容按仓库 Apache-2.0 提供。

评审时先只看问题与证据，确认 rubric 是否成立；再看候选回答，逐项记录 supported / unsupported / unjudgeable 及原文定位。生成输入、人工期望、候选输出分别保存。两名独立评审有分歧时保留两份记录及裁决，不能让生成模型自行批准为 gold。

这组测的是证据使用与推断边界；要测搜索规划，还需为每题加入固定的查询—结果回放或真实检索日志。暂不自动用模型 judge，避免未校准分数代替人工结论。
