# StripSearch：人物入口、Person Object 与 DSH 重构提案

日期：2026-09-26。状态：完整设计提案与合成交互稿；不代表生产实现、模型质量或低成本目标已通过。用户目标：一个姓名或社交链接即可开始，系统完成必要身份解析、跨平台公开资料研究和结构化输出，尽量减少无必要的人为判断。

## 建议结论

**以“人物”作为产品主对象，以 DSH 作为受约束的 Agent 执行层，以 StripSearch 的持久控制器负责身份、证据、权限和费用。** 首访只输入人或链接；明确个人主页不重复弹确认；身份有歧义时才问一个最有区分力的问题。结果先给可读认识，再按需展开证据和来源。

“低价的长报告”不足以构成优势。值得投入验证的是：一次建立可修订的人物资料，以后切换用途、继续阅读、追问和刷新只处理增量，降低每次获得有效理解的成本。
