# 独立 Review 与验证

日期：2026-09-26。这是设计评审，不能替代真实模型、采集器和生产验收。

## 1. 三条独立审查线

- 现状审查：独立阅读生产输入、provider、runner、存储和导出；确认当前以单次 run 为中心，不能把旧原型当实际新界面。
- 技术事实审查：官方 DSH/DeepSeek/Exa 文档与固定 DSH 源码；独立复算成本。
- 设计反对性审查：检查少确认与错人风险、Person/Report 关系、恢复、预算、输出一致性及评测分母。

## 2. 关键评审发现与处理

| 发现 | 严重性 | 处理 |
| --- | --- | --- |
| 贴 URL 被误当成跨平台身份全部确认 | P1 设计门槛 | 明确账号锚点与跨平台 IdentityLink 分开；帖子角色单独解析 |
| stable platform ID 被写成每个主页的前置条件 | P1，首轮发现 | 内部 anchorId + URL/内容版本；平台 ID 可空；独立网站不被阻断 |
| 工具账遗漏 DSH 内部 root/child/compaction/search 费用 | P1，首轮发现 | 全模型出站统一预算代理；禁止 worker 直连和携带供应商真实 key |
| 支持率高但只输出一条简单事实，合格成本分母不明 | P1，首轮发现 | 冻结逐题 rubric、关键覆盖与 unknown；全部原子断言/全部尝试计数 |
| Person 是巨大可覆盖 JSON，混淆稳定引用与事实稳定 | P1 设计门槛 | 归一化实体 + 不可变 revision + 任务快照 + CAS |
| DSH session/idle 被当持久研究成功 | P1 设计门槛 | 独占 job attempt runtime；领域 checkpoint；结构化产物验证收据 |
| 多格式重新生成或撤回只改 UI | P1 设计门槛 | 同一权限过滤投影渲染；依赖失效传播；已下载文件不可召回 |
| 默认日志上传、shell 权限进入产品 runtime | P1 设计门槛 | 自定义最小 profile；实际出站断言和隔离测试成为发布门禁 |
| 中文“工作日”与调休混淆、日志键可复制性不准确 | P2 文档事实 | 改为周一至周五、插件实例 config.enabled；不杜撰 Cordis selector |
| 再加一个原型但没有采用路径 | P2 产品债 | README 明确旧稿与新提案关系；分批迁移共享契约，不声明上线 |

前三项新发现已在 PRODUCT、TECHNICAL、COST-EVAL 修订；各项设计门槛在正文都有具体契约和验收。此表记录设计防线，不表示当前线上已发现对应安全漏洞。

独立 reviewer 已回读确认三个 P1 关闭：**设计文档范围内无未解决 P0/P1**。该结论不覆盖尚未实施的系统或实际研究效果。

## 3. 成本复核

独立 Decimal/Python 计算确认：缓存情景模型+Exa 三档空闲/高峰为 0.0211/0.0232、0.1083/0.1356、0.2822/0.3644 美元；全 miss 高峰为 0.0232、0.1650、0.4820 美元。没有平台费等未计项，不是可承诺的最终用户价格。

## 4. 验证范围

已实际查看公开线上页面桌面与手机状态、展开主页折叠，读取线上 release revision。没有登录或研究真实人物。浏览器控制连接两次超时后，使用独立 headless Chrome 观察公开页面；未修改浏览器用户数据。

交互稿的状态与导出验证单列在原型目录 README 中；其通过只证明合成页面交互，不证明身份、检索、模型研究或真实价格。设计静态检查只检查文档链接、样例和格式完整性。

最终合成稿已通过桌面/390px 的十组浏览器检查，0 JS 错误、0 外部请求；实际下载 JSON/HTML 比对事实与来源。打印仅验证触发，IME 为组合事件模拟。独立代码 review 发现并修正“项目更新归因个人”的 P1 后复核关闭。截图、范围与成对判断见[原型验证](../../../design/explorations/person-object-2026-09-26/VALIDATION.md)。

## 5. 最终产品判断

建议推进 DSH 纵向样机：公开主页 → 身份锚点 → 少量合格来源 → 证据化 Person → 同快照三格式。先证明资料归属、恢复和成本，然后增加跨平台范围。

不建议首版默认关系图谱、不设上限地扩所有平台、把用户零干预作为唯一指标，或为了低价省掉反证/归属验证。真正应隐藏的是内部实现复杂度；会改变用户判断的不确定性仍需呈现。

未解决的实证问题：真实平台可读性、长采访处理效果、DSH live 工具兼容、身份精度、单位合格任务成本、用户对 A/B 的偏好。它们作为实施门槛保留；本轮没有编造通过结果。
