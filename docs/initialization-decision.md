# 初始化验证决策 · 2026-09-20

状态：实验已运行；下文保留实施前的问题与停止规则，结果见 [验证记录](initialization-validation.md)。类型：logic / CLI。生产架构仍见 [architecture.md](architecture.md)。

## 一个问题

在已有显式标注的身份与证据图上，**共享 canonical report + 修订门禁**能否在身份撤销、来源不可读或导出权限收紧后，阻止 JSON 与 Markdown 输出失效结论，并保留不受影响的结论？

- A：可以；把门禁放进共用 core，CLI / MCP 只读同一有效快照。
- B：不可以，或只有删掉全部内容才安全；先修改依赖模型，不进入真实采集集成。

这不是“模型能否正确研究人物”的实验。输入断言、归属和证据边是人为编写的合成数据，不能用它测抽取、语义蕴含、检索质量或真实精度。

## 什么证据改变决定

正常案例能保留已归属且可读的证据；任一反例能泄露受限断言、导出旧报告，或 JSON / Markdown 增减事实，则拒绝当前方案。保留正常的独立分支，避免通过空报告虚假获胜。

最小可观察失败：撤销 source → person 的关联后，任一依赖的 claim / event / hypothesis / profile 仍出现在当前导出中；或旧 revision 仍能作为有效结果读取。

审查补充：区分“原网页目前不可访问，但已有合法保存、可核验的历史快照”与“本地可用的证据正文被撤回/清除”。前者不自动否定历史证据，后者必须有合法失效转移并关闭旧报告的正常导出；不能只证明创建时拒绝 body=null 的错误输入。

## 输入与观察

探针放在 `probes/evidence_gate/`，使用 Python 3.12 标准库，便于无需安装依赖地运行。它不决定生产语言。输入含合成人物、来源、摘录、身份边、断言、事件、假设及权限；SQLite 只保存探针快照和修订状态。每例输出输入、操作前后状态、trace、导出和独立检查结果。

至少覆盖：正常支持、同名未绑定、不可读材料、断裂引用、撤销传播、撤销身份依据、旧版本拒绝、公共导出权限继承、混合证据、重启读取与双格式一致。失败输入必须有明确错误，不能被静默修复成成功。身份依据中的自身引文是支持记录，不自动形成另一条身份依赖；跨来源身份依据需要完整有效链并防止无锚点循环。

## 停止规则与范围

本次只进行一轮探针实现、独立审查和必要修复；实现时间盒 45 分钟，若到期仍无法排除核心反例，则记录 inconclusive，不扩建完整产品。检查全部完成后停止扩张范围。未裁决案例保持 `synthetic / discovery / unreviewed`。

不包括：LLM 生成、真实人物、网络适配器、付费 API、MCP server、UI、任意文件导入、完整 job 生命周期、生产级存储/删除、基准或用户收益实验。仓库原有 12 个种子 case 保持原状；探针检查不是对它们的研究评测。

## 结果记录规则

结论只能为 supported / rejected / inconclusive；分别保存观察事实、自动判定、人的决定（未确认则 unreviewed）、AI 假设及未验证项。自动通过不把样例升级为人工 gold。结果记录在 [初始化调研报告](initialization-research.md) 与 [验证记录](initialization-validation.md)。
