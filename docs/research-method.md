# 人物研究方法

研究单位是**可定位的事件和断言**。方法用于公开职业活动与明确授权材料；任何推断都要说明什么证据会使它失效。

## 1. 先把问题与人锁定

把“深挖某人”改写为可回答的问题：某个公开项目究竟贡献了什么？经历转折发生在何时？一次公开承诺是否有后续行动？不能把“找黑料”当作默认检索目标。

候选人物各有独立 `person_id`。种子主页只是用户意图的锚点；确认主页属于谁仍需要证据。明确的公开自链、机构对具体作品/个人的指向是强线索；姓名、头像、用户名与模糊履历只能辅助。不能用检索排序或 LLM 给出的 0.95 当身份概率。

对每个新来源维护 `candidate / linked / disputed / rejected`：只有 linked 材料可以支持目标结论。即使目标已经 resolved，新找到的同名资料也必须重新过归属关。出现互斥身份线索时保留候选，返回 `needs_input`，不要生成一篇混合传记。

记录决策依据、相反证据和决策版本。身份链接撤销后，追溯并失效其下游事实、事件与假设。人确认“我要研究这个主页”不等于确认该主页上的所有说法。

## 2. 建立三条证据线

| 证据线 | 找什么 | 它能证明到哪里 |
|---|---|---|
| 自我叙述 | 访谈、个人文章、公开介绍、当时的承诺 | 此人曾这样表达；不能直接证明成效、动机或所有经历 |
| 行动与作品 | 可归属的提交、作品版本、公开决策、兑现与后续维护 | 某时发生了具体行动；团队成果仍需分解个人贡献 |
| 第三方观察 | 有上下文的亲历记录、事件报道、具名公开评价 | 观察者说了什么、依据是什么；不能由评论数量推出真伪 |

按事件建立小型来源矩阵，分别搜索支持与反证。优先读原作、原公告、原始访谈，再读总结。多个域名转述同一公告，只算一个原始来源组。网页存档能证明某版本存在过，不能自动证明其中说法为真。

## 3. 用事件理解经历

每个事件记录以下最小内容，缺失则填 unknown：

| 字段 | 要回答的问题 |
|---|---|
| 时间与情境 | 发生时间、当时角色、已知约束是什么？不要把发表日期替代事件日期 |
| 当时表达 | 他当时说要做什么？是否有原始记录？ |
| 实际行动 | 可核验做了什么、个人贡献是什么？ |
| 可观察代价 | 投入、承诺或机会成本是否有直接记录？不能由行为倒推心理代价 |
| 结果与后续 | 有什么可归属结果？后来修正、维护或放弃了吗？ |
| 相反证据 | 有什么记录不符合最初解释？ |

行为信号的价值取决于具体性、时间连续性、归属强度与独立证据，**稀有本身不代表可靠**。例如公开修正错误并持续维护作品，通常比一句“重视质量”提供更多可检验材料；仍不能据此断定这个人在所有场景都可靠。

经历转折按“前状态 → 可见事件 → 后状态”呈现。离职后创业是时间序列；除非有可信直接证据，不把离职原因和创业动机补成因果故事。

## 4. 评论与评价怎样读

- 保存原评论 URL、父帖、上下文、时间与必要短摘录；区分亲历描述、转述、观点和纯情绪。
- 关系只写有公开依据的部分。利益冲突不清楚就标 unknown，不推断秘密关系。
- 以与研究问题有关的具体事件采样，记录排序方式、时间窗、已读页数、游标、去重数与无法读取部分。
- 同时检查不同时间段、相反评价与后续澄清；不把热门评论当总体意见，也不把匿名指控提升成事实。
- 只在任务相关时引用必要的观察者身份；不对路过的评论者展开档案或社交关系搜索。

## 5. 解释必须能被推翻

行为假设模板：**在什么情境下，观察到什么重复选择；哪些事件支持；哪些事件反对；还有什么解释；下一条什么证据会改变判断。**

事实、自述和解释分层显示。没有足够独立事件时只交付事件账本，不勉强写“人格模型”。未经校准不展示精确概率，不生成统一的人格或可信度评分。

## 6. 本地档案与停止规则

用户显式选择导入的文档要保留原路径的内部引用、内容 hash、段落/页码、作者与时间、授权范围。私人笔记是观察记录，不自动成为第三方真相。对外报告不能把本地绝对路径当公开 URL，也不能上传整个知识库给采集供应商。详细导入与导出机制见[架构](architecture.md#本地档案也是有边界的来源)。

关键问题已覆盖且连续两轮没有新增独立证据，可以停止并记录理由。预算、访问限制或身份不明也必须停止，报告 partial / needs_input 及缺口。停止并不意味着互联网信息已穷尽。

方法参考：[Bellingcat 编辑标准](https://www.bellingcat.com/about/editorial-standards-practices/)对来源、语境和修订的要求；[Verified Person Research](https://github.com/liewcf/verified-person-research)的人物经历与观点研究思路。它们是方法参考，不是本项目效果已经成立的证据。
