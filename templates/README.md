# 三种工作模板

只记录会影响下一步决定的信息。事实必须有证据；没有运行过的实验不填结果。

| 何时用 | 模板 | 写到哪里 |
|---|---|---|
| 开始一次研究、复核一个事件 | [Research](research.md) | 用户授权的本地 workspace；真实档案不提交到项目仓库 |
| 比较检索器、prompt 或工作流 | [Experiment](experiment.md) | 可公开、去标识的运行摘要；原始 trace 留本地 |
| 改变接口、存储或产品取舍 | [Decision](decision.md) | 仓库设计变更；Notion 留决定摘要与链接 |

每次使用复制一份并填写。不需要为了模板完整而编造负责人、日期、数字或结论。Notion 内的对应模板是便捷入口，版本化定义以此处为准。
