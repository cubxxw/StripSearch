## 成对设计判断

相对值以 A 对比 B，+1 代表 A 更适合该问题，-1 代表 B；这是设计判断，不是用户研究分数。

| 问题 | 相对判断 | 可见依据 |
| --- | --- | --- |
| 首访能否迅速开始 | +1 | A 首屏只有一个研究输入；B 先显示已有阅读内容 |
| 既有人物的回访价值 | -1 | B 直接展示上次内容和未解问题；A 仍需新输入 |
| 证据机制可见 | 0 | 两者进入同一人物页和引用展开 |
| 页面结构差异 | 0 | A 为单列输入，B 为人物索引与阅读正文，确有结构差异 |
| 移动与键盘可行性 | 0 | 两者均通过本轮对应功能检查 |

推荐 A 首访、B 回访，不强迫用户在两个产品之间选择。若真实回访没有持续内容，B 应先退化为已保存人物。无真实用户偏好实验，不宣称视觉效果已获用户认可。
