# 人物入口 / 回访阅读 · 合成交互设计稿

`index.html` 是自包含离线原型，无依赖、网络请求或模型调用。它演示 2026-09-26 的 Person Object 产品设计，不替换 `apps/web`，不代表真实身份解析、采集、订阅或 Agent 已实现。

打开 `index.html`，或由本地静态服务器提供此目录。全部人物、作品与摘录为原创合成材料；`example.org` 仅为标识，不应抓取。

可操作路径：

1. A 人物入口：点击“填入合成主页示例”，提交后直接进入研究状态，无重复确认；点击“演示：展示结果”打开阅读页。
2. 填入“林舟”并提交：显示两位独立合成人物；选定对象后继续。其他输入保留原文并诚实提示仅支持演示。
3. B 回访阅读：查看固定合成阅读状态，打开同一人物的综合了解或会面准备视角。它不表示真实订阅能力。
4. 人物阅读页：展开出处，区分事实、自述、未知；视角切换复用同一对象。JSON / HTML 下载来自同一对象，PDF 按钮调用浏览器打印，明确不是服务端生成。

支持按钮键盘操作、可见焦点、IME 组合输入保护、⌘ / Ctrl + Enter，控件至少 44px。研究过程由显式演示按钮推进，不使用计时器伪造采集进度。页面不持久化输入，刷新会回到初始状态。打印与 HTML 导出均使用当前视角；JSON 保留完整人物对象并携带 reportView。三个出口使用相同事实、来源和人物索引。

真实浏览器主线与 390px 检查已通过，详见 [验证记录与截图](VALIDATION.md)。设计和实现边界仍按上文保留。
