# 设计探索验证

日期：2026-09-24。以下验证针对本目录 HTML 原型，不代表原生 iOS、真实采集、AI 质量或产品留存验证。

## 实际完成

- 读取现有项目说明、Web 设计与路线；检查已有未提交文件，原文件保持原样。
- Open Design 安装目录枚举 152 个系统包；12 个相关系统定向初筛，另比较具体手机、编辑式、纸质、柔和及社媒模板。实际打开 4 个模板示例截图。包名与来源文件摘要见 [research-receipt.json](research-receipt.json)。
- 当前 Signal Atlas：桌面/手机首屏、后续图谱与流程区、候选账号交互均实际查看。
- 原型 A/B：375 / 768 / 1440px × 首页 / 阅读 / 人物 / 帖子，共 24 组浏览器检查，没有页面横向溢出或捕获到的脚本异常。原始回执见 [browser-receipt.json](browser-receipt.json)。
- 手机 390px 实际检查姓名错误、同名选择、研究暂停/跳过、人物来源、关注面板、帖子追问、预设反例、出处查看、自由输入提示。
- 专用 localStorage 的关注状态、每周频率和收藏经过刷新读回；没有创建真实订阅或通知。
- 深读筛选从 4 篇变为 3 篇，并展示入选理由。
- A/B 对照页的「随手追问」同时打开两个面板；桌面「名字入口」正确显示两个首页，620px 预览容器无横向溢出。
- 减少动态 + 深色模式：媒体查询命中，活动动画为 `none`；暂停后活动动画节点为 0；页面无横向溢出。
- 网络观察窗口记录 229 项请求，无外部 HTTP 请求。观察包含本地页面资源和浏览器扩展资源，不等于生产离线认证。
- `node --check reading.js` 与仓库 `python3 scripts/check_design.py` 通过。后者只检查既有设计基线的一致性，不检查模型表现。

## 本轮修正

- 暂停回放后同时停掉视觉活动标记。
- 常规按钮最小触控区域 44px；原文选段按钮补充 `inline-block` 与 44px 最小高度。
- 明确保留面板的触发控件，并在 Escape/关闭时恢复焦点；切换预设和出处时重新放置面板内焦点。
- 保留当前查询参数，避免从带预览参数的页面进入帖子时触发整页重载、丢失阅读位置。
- 非陈遥文章不复用他的评论区内容；未编写预设答案的帖子明确提示。
- 双列封面重新排字，作者行精简为作者、日期与阅读时长。
- 对照页通过同源消息切换内嵌页面，修复仅改变片段地址时追问面板未打开的问题；修复桌面预览的网格最小宽度与缩放。

回执包含修正前的自动化观察与修正后的 `_final` 字段，不能把早期失败读回当作最终结论。最初 `Page.reload` 后立即操作曾遇到元素尚未就绪，后续使用导航完成和新状态读回重测。

## 仍待验证

- 用户对 A/B 的审美偏好、真实内容下的阅读节奏、回访与学习效果。
- 原生 iOS 的键盘、安全区域、动态字号、VoiceOver、触觉、手势返回、离线与跨端同步。
- 搜索/身份判断、全平台读取、评论覆盖、去重质量、真实 Agent 事件、模型引用正确性。
- 共享元素动画、完整原生转场和真实滚动性能。本轮没有 Lighthouse 或实际设备帧率测量。
- 订阅来源勾选与历史范围是流程示意，尚未持久化；自由追问不调用模型。
