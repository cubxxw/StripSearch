# 多平台研究 · 新视觉探索

## 已选 A：操作优先的深化（2026-09-21）

用户选择 A，要求减少无效修饰、增加交互图与 Action、深入使用和配置体验，本轮禁止 Pi。保留 B 作为历史挑战稿，不再呈现主导航 A/B 选择。

对照 [Octen](https://octen.ai/) 的首屏输入、并行查询流程展示与分步骤接入，提取“动作与可见结果紧邻、能力逐层展开”的机制。保留 StripSearch 薄荷绿与证据归属语义，不复制品牌资产、性能指标或服务能力。

布局分支：A1 为原来的左输入 / 右星图；A2 为紧凑输入 + 全宽交互图 + 就近证据检查器。采用 A2，让主要空间用于操作，减少口号、轨道与重复说明。仍以旧版 A 截图作为前后对照。

- 官网：一行主张、一个线索输入、一个可操作图谱。节点选择和证据检查就近反馈；同名候选不画已确认连线。
- 首次使用：平台范围 → 研究方式 → 检查并开始明确标注的合成研究。至少选择种子来源外的一个平台才可运行；非合成人物输入不得伪装产生真实结果。
- 工作台：图谱 / 账号 / 结论 / 时间 / 核查，节点选择、缩放、排除与恢复候选；来源撤回仍向下游传播。候选排除不等于身份否定。
- 配置：研究偏好、数据源、显示；仅非敏感偏好持久化。当前报告使用启动时的范围快照，配置调整仅用于下次研究。报告与导出均按已选范围与候选排除状态过滤。
- 数据源配置只保存适配器草稿，不收集真实密钥，不调用验证网络。连接检查明确返回“后端未连接，未验证”，配置导出使用环境变量名，不包含密钥。
- 动效：操作引发的连线高亮、面板切换、阶段推进、节点选中；停留时静止。系统减少动态与应用开关均可关闭动画。键盘与手机可完成同一动作。

状态：独立合成原型，入口 `next/index.html` 与 `next/dossier.html`。不替换既有 Web alpha，不代表新增平台已接通。

## 共同产品契约

访问者：准备采访、研究公开创作与职业活动，或检查自己的公开足迹。冲突：结果很多，但账号归属和结论依据不清楚。下一步：提供公开姓名、用户名或主页，查看分平台的候选，再逐条检查证据。

- 输入：姓名 / 主页、用户名、本人或已授权邮箱；图片仅用于本人或授权图片的公开出处核查，不做人脸识别或以相貌建立身份关联。此原型不上传、不检索真实输入，所有输入进入明确标注的林舟合成演示。
- 结果：每个平台可有零至多个账号；归属有依据、待核查、冲突分别保留。无匹配、读取失败、未配置不可混同。
- 身份证据与事实支持分别呈现；同名、相似头像和相同用户名均不能直接建立同一人关系。
- 事实、推断、未知分别显示；事件有发生日期和材料日期；关系只呈现可定位公开互动，不推断私交。
- 五个评价维度呈现核查项与证据，不编造 benchmark 百分比。来源撤回同步影响相关结论和导出。
- 平台能力是规划：GitHub 真实 alpha 能力保留在原入口，Exa 真实配置未验收；TikHub / Apify / Maigret 均未在本原型调用。

## 历史 A/B 路径（深化前）

| | A · Signal Atlas | B · Open Dossier |
|---|---|---|
| 主张 | 从散落线索，看到有依据的连接 | 打开一个人公开工作的多平台档案 |
| 空间 | 深色与薄荷绿、不对称大标题、可点击账号星图 | 暖白与朱红、出版物标题、竖向档案与时间切片 |
| 首屏 | 左侧输入，右侧图谱，点节点检查归属 | 大标题与检索条，平台索引，展开材料 |
| 中段 | 跨平台分布 → 证据核查 → 覆盖矩阵 | 平台目录 → 时间切片 → 事实与未知 |
| 识别交互 | 选中节点同时强调该条证据连接 | 选择时间片展开当期材料，保持上下文 |
| 避免 | 黑客监控屏、装饰性雷达、泛 AI 渐变球 | 普通博客、三卡营销页、静态 PDF |

A 架构比较：输入优先的星图与全屏演示优先。选择前者，让下一步在首屏可见；保留 B 档案叙事作为挑战方案。原型在两个方向中共享结果状态和证据模型，样式不能创造新事实。

## 初版动效与交互（深化后的 A 以上文为准）

首页有限次数的节点入场和连线描绘；悬停/焦点揭示归属；进入工作台时内容分组出现。300ms 左右状态切换，原生滚动，不锁滚轮。减少动态偏好下取消移动，信息仍完整。移动端改为可触控平台节点与单列结果；原生 dialog 支持 Escape、焦点返回。

工作台：平台过滤、账号详情、事实 / 时间线 / 关系 / 核查切换、来源检查、来源撤回与恢复、合成零结果与失败重试、模拟暂停继续、Markdown 导出。共享状态由 `next/demo.js` 提供。
