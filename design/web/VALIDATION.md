# Web 原型验证

日期：2026-09-20。范围：Open Design 生成的 A/B 方案，以及从 A 收敛的 `index.html`。这是合成样例交互验收，不是研究引擎或模型效果验证。

## 结果

- Node 22.23.2 / jsdom 30.1.0：**21 项通过，0 项失败**。依赖安装与离线测试分开。
- 仓库设计一致性检查通过。原来的 12 个研究案例未在本轮运行，不宣称研究准确率。
- Codex 浏览器实际操作覆盖首页输入、身份拒绝、暂停/继续、脚本追问、来源撤回与下载。
- 撤下 S2 后，作品事实、推断、机制结论、时间线事件和既有依赖回答均显示待复核。实际下载文件中，对应语句逐条附有撤回标记。
- 手机来源抽屉：Shift+Tab 保持在弹层中；Esc 关闭并把焦点还给「来源」。检查期间未观察到浏览器 console error。
- 字体有本机回退，不依赖远程字体、图片或脚本；未连接任何研究提供方。

## 修复的原稿问题

1. 手机首屏的边界说明挤走研究框：移至页面末尾的可展开说明，并把主问题和动作提前。
2. 研究工作台混在很长的营销页中：拆为首页与独立 Chat 视图。
3. 来源撤回只修改一个事实块：引入共享依赖表，同步所有相关语句、已有回答和 Markdown。
4. 无报告仍可下载、畸形 URL 通过、抽屉焦点逃逸：补状态门禁、URL 解析与焦点约束。
5. 首屏被活动日志占满、追问框藏在报告底部：完成后折叠过程，输入框独占底部一行。
6. 原稿把 2025 年的自述来源用于支持无材料的 2022 时间点：最终样例仅展示来源支持的 2024–2025 事件。
