日期：2026-09-20。当前范围：精简文案、快捷操作、来源排除与撤销、复制报告、步骤反馈。内容仍为合成示例，不验证研究引擎或模型效果。

## 本轮结果

- Node 22.23.2 / jsdom 30.1.0：**36 项通过，0 项失败**，无新增依赖。最终修改后重新运行通过。
- `python3 scripts/check_design.py` 与 `git diff --check` 通过。静态检查不等于真实研究案例通过。
- Codex Chromium 实际操作：清空并返回焦点、示例填入、Ctrl+Enter 提交、错误身份拒绝、一键追问且保留草稿、复制报告成功后读回剪贴板、手机出处抽屉内排除与撤销。
- 排除 S2 后的 4 类依赖结论与已有回答同步标记；撤销后恢复。移动抽屉内操作后焦点仍在抽屉，背景保持 inert。
- 新增异步测试证明：复制中不重复提交；重置后旧复制结果不显示成功；复制期间来源变化会提示重新复制；失败/缺少 API 可改用下载；进度暂停不前进且只完成一次。

| 主按钮底部距页面顶部 | 580px | 442px |
| 文档宽度 | 375px | 375px |

手机 Chat 修复了快捷追问撑大网格的问题；已实测文档宽度为 375px，输入和发送按钮同排，追问横向滚动。正文与输入区独占网格行，不重叠。首页与手机 Chat 已实际截图查看，截图显示在本次验证对话中。

## 发现并修复

1. 重复声明、装饰英文状态与无效果的模式按钮：删除；示例说明收进折叠，候选步骤明确告知固定示例不会随问题改变。
2. 手机工作台被追问按钮撑到 579px：限制网格列最小宽度，保留追问局部横向滚动。
3. 手机发送按钮单独占行：与输入框同排，移除重复发送说明。
4. 报告重置或排除来源后，旧剪贴板回调仍可能提示成功：引入请求与报告版本检查，补充两项回归测试。
5. 暂停后的残留回调仍可能推进步骤：显式检查暂停状态，补充已有进度测试；进度条用 transform 更新。
6. 不可访问的来源显示成引文：改为“没有拿到原文”，不加引号。

## 本轮验证限制

最后检查时浏览器自动化连接中断，原生 Open Design 控制连接也不可用。本地预览 HTTP 服务仍正常，修改文件已同步且逐字节校验一致。

因此，本轮没有完成最后一次深色、减少动态偏好切换，以及“暂停”改名与进度条 transform 修改后的浏览器复查。相关状态逻辑已通过最终 DOM 回归；不能把它写成完整视觉验收。深浅色令牌与系统媒体查询沿用前一版已验证实现。
